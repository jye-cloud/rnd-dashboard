← 과제 관리로 돌아가기

📋 CSV 입력 양식

사용 방법
① 엑셀에서 아래 컬럼 순서대로 데이터 작성
② 첫 줄은 헤더 (변경 X)
③ 엑셀에서 전체 선택 → Ctrl+C → 아래 박스에 Ctrl+V (엑셀 복사 그대로 OK)
④ 검증(미리보기) 버튼으로 확인 → 일괄 등록 클릭
※ 모두 division1='용역' 으로 자동 저장됩니다.
1. 과제명필수
2. 책임자선택 (빈 칸 OK)
3. 기관명선택 (발주 기관)
4. 부처선택 — 보통 공란, 필요 시만 입력
5. 시작일필수, YYYY-MM-DD 또는 YYYY. MM. DD 형식 모두 OK
6. 종료일필수, 같은 형식
7. 연차별 총액(VAT 포함) • 단년: 55000000 (숫자 1개)
• 다년차: 33000000;22000000 (세미콜론 ; 으로 1차;2차 구분)
• 다년차 기간인데 금액 1개만 입력하면 → 시작년도에 일괄 처리 (시스템에서 등록 후 수동 분배 가능)
8. 키워드선택, 여러 개는 | 로 구분 (예: ESS|안전성)
9. 비고선택
📌 입력 형식: 엑셀에서 셀 복사한 그대로 (탭 구분) 또는 콤마(,) 구분 둘 다 작동
